# MSP430 Embedded Systems

A collection of embedded systems projects developed using the MSP430 microcontroller, focusing on microcontroller programming, hardware control, timers, PWM, GPIO, interrupts, and real-time system behavior.

## Projects

### PWM LED Dimmer

Implemented PWM-based LED brightness control using the MSP430's timer peripherals.

**Concepts:** PWM, Timer peripherals, GPIO, duty-cycle control

---

### Digital Stopwatch

Developed a timer-based stopwatch using the MSP430 to implement real-time counting and user input control.

**Concepts:** Timers, interrupts, GPIO, real-time control

---

### Timer-Based Alarm System

Implemented timer and PWM functionality to generate and control an alarm output.

**Concepts:** Timers, PWM, GPIO, embedded control

---
